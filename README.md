# Математика без потолка

Тренажёр по математике и физике. По математике есть 5 и 6 класс. В 5 классе 12 тем по дробям. В 6 классе 21 тема: рациональные числа и алгебраические выражения. По физике есть 7, 8 и 9 класс. В 7 классе глава «Взаимодействие тел» из 6 тем. В 8 классе глава «Основы электростатики» из 7 тем. В 9 классе глава «Основы динамики» из 8 тем. Темы идут по КТП 2026-2027 учебного года.

Ребёнок выбирает предмет и свой класс. Потом проходит короткую разведку. Разведка начинается с сегодняшней темы по КТП. Потом ребёнок идёт по карте тем. Не понял объяснение? Приложение объяснит проще и по шагам. В задачах с буквами ответ набирают на клавиатуре с буквами и знаками. Не хватает основы? Приложение само вернёт к нужной теме младшего класса.

Курс разбит на главы по разделам КТП. В конце главы тест из 20-30 вопросов без подсказок. Следующая глава открывается только при 90% верных ответов. Если меньше, приложение показывает ошибки по темам и даёт работу над ошибками. Потом новый тест с другими задачами. На карте виден процент пройденного курса класса.

Сайт работает без сервера. Прогресс хранится на устройстве ученика. У каждого предмета свой прогресс. Имена и отметки никуда не отправляются.
