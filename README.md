# Математика без потолка

Тренажёр по математике для 5 и 6 класса. В 5 классе 12 тем по дробям. В 6 классе 13 тем по рациональным числам. Темы идут по КТП 2026-2027 учебного года.

Ребёнок выбирает свой класс и проходит короткую разведку. Разведка начинается с темы, которая идёт по КТП сейчас. Потом ребёнок идёт по карте тем. Не понял объяснение? Приложение объяснит проще и по шагам. Не хватает основы? Приложение само вернёт к нужной теме младшего класса.

Сайт работает без сервера. Прогресс хранится на устройстве ученика. Имена и отметки никуда не отправляются.
