# Математика без потолка

Тренажёр по математике для 5 класса. Сейчас в нём 12 тем по дробям.

Ребёнок проходит короткую разведку. Потом идёт по карте тем. Не понял объяснение? Приложение объяснит проще и по шагам.

Сайт работает без сервера. Прогресс хранится на устройстве ученика. Имена и отметки никуда не отправляются.
