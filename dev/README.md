# Проверка приложения

Здесь лежат тесты и проверки в браузере. На работу сайта они не влияют.

- node dev/test.js - проверяет все задачи всех тем. Генерирует задачи тысячи раз и ищет ошибки.
- python3 dev/smoke.py - путь ученика 5 класса в браузере.
- python3 dev/smoke6.py - вход и разведка ученика 6 класса.
- python3 dev/smoke6b.py - слабый ученик 6 класса: объяснения и разбор по шагам.
- python3 dev/smoke6c.py - все темы раздела «Алгебраические выражения» с вводом ответа с буквами.
- python3 dev/kbd6.py - ввод выражения с клавиатуры компьютера.
- python3 dev/ctest.py - тест по главе: не сдан, работа над ошибками, сдан со второй попытки.
- python3 dev/smokep8.py - физика 8 класса: все темы главы «Основы электростатики», тест по главе и переход в математику.
- python3 dev/site_check.py - сайт открывается без ошибок.

Для проверок в браузере нужны Playwright и Google Chrome. Снимки экрана сохраняются в /tmp/mbp-shots.

artifact-index.html - страница для ссылки в Claude. Отличается от index.html только значком и отсутствием офлайн-режима.
